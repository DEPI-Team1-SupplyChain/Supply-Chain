# Supply Chain Analysis

A DEPI graduation project focused on analyzing supply chain data to explore product sales, revenue, inventory, suppliers, shipping, manufacturing, and product quality.

## Project Objectives
- Clean and prepare the dataset for analysis.
- Explore business questions related to sales, inventory, supplier performance, shipping, costs, and product quality.
- Create visualizations and a Power BI dashboard to present the findings.
- Prepare a final report and presentation with practical recommendations.

## Dataset
The dataset contains product and supply chain information, including sales, revenue, stock levels, suppliers, shipping, manufacturing, and defect rates.

## Tools
- SQL
- Python: pandas, Matplotlib, and scikit-learn
- Power BI
